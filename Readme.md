# TilapiaFreshAI

## Sobre o projeto

A tilápia é o pescado mais consumido no Brasil, mas é também uma matriz biológica altamente perecível. O controle de qualidade tradicional depende de análise sensorial humana — subjetiva e pouco reprodutível — ou de colorímetros, que sofrem com a alta variabilidade biológica das amostras.

O **TilapiaFreshAI** propõe uma alternativa: um sistema de processamento digital de imagens e aprendizado de máquina capaz de estimar, a partir de uma fotografia padronizada, há quantos dias um filé de tilápia foi abatido.

O projeto nasce como suporte quantitativo a uma pesquisa de doutorado sobre o uso de óleos essenciais na conservação do pescado, fornecendo diagnósticos objetivos e livres de viés humano para validar a eficácia desses conservantes naturais.

## Objetivos

> Desenvolver um sistema computacional baseado em processamento digital de imagens e aprendizado de máquina, capaz de classificar automaticamente o estágio de degradação pós-abate de filés de tilápia.

- Extrair características visuais de **cor**, **textura** e **morfologia** das amostras
- Treinar e avaliar modelos de classificação para estimar o tempo pós-abate
- Fornecer diagnósticos automatizados e reprodutíveis, como suporte à pesquisa de doutorado parceira
